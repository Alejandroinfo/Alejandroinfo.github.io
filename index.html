Predicting Dangerous Streets with ML

A classifier that flags high-risk streets across 127K New York City street segments, built from crash records and street-infrastructure data.

  • Compared logistic regression, decision trees, random forests and a neural network (MLP), using SMOTE to handle class imbalance.
