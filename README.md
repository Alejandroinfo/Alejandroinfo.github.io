# alejandroinfo.github.io

Source for the portfolio of **Alejandro Armas Braithwaite**, a data scientist and economist (M.S. Computational Analysis and Public Policy, University of Chicago).

**Live site:** https://alejandroinfo.github.io/

The site is a single static page (`index.html`) with no build step, served by GitHub Pages.

- `index.html`: the page itself (projects, experience, skills, contact)
- `images/`: project thumbnails, profile photo and the Chicago crime report (PDF)
- `cv/`: downloadable resumes (Data and Research versions)

To update it, edit `index.html` and push to `master`. GitHub Pages republishes the site automatically.
